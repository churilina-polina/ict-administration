## 1. Что сделано

Развёрнут демо-сервис на FastAPI и полный стек наблюдаемости вокруг него:

- **метрики** — Prometheus + Grafana (метод RED);
- **логи** — Loki + Promtail, просмотр в Grafana;
- **трейсы** — OpenTelemetry + Jaeger;
- **оповещения** — Alertmanager с доставкой в webhook-приёмник.

Всё поднимается одной командой `docker compose up`.

---

## 2. Состав стека

| Компонент | Образ | Зачем нужен | Адрес |
|-----------|-------|-------------|-------|
| demo-service | собирается из `./service` | тестовый HTTP-сервис с эндпоинтами нагрузки, отдаёт метрики, пишет JSON-логи, шлёт трейсы | http://localhost:8000 |
| Prometheus | `prom/prometheus:v3.1.0` | собирает метрики сервиса, вычисляет правила алертов | http://localhost:9090 |
| Alertmanager | `prom/alertmanager:v0.28.0` | принимает сработавшие алерты, шлёт уведомления | http://localhost:9093 |
| webhook-receiver | `mendhak/http-https-echo` | принимает уведомления от Alertmanager и печатает их в лог | http://localhost:8081 |
| Grafana | `grafana/grafana:11.4.0` | дашборды по метрикам и просмотр логов | http://localhost:3000 |
| Loki | `grafana/loki:3.3.2` | хранилище логов | http://localhost:3100 |
| Promtail | `grafana/promtail:3.3.2` | читает файл логов сервиса и отправляет в Loki | — |
| Jaeger | `jaegertracing/all-in-one:1.65.0` | приём и просмотр распределённых трейсов | http://localhost:16686 |

### Схема потоков данных

```
                 ┌──────────────┐  scrape /metrics   ┌────────────┐
                 │ demo-service │ ─────────────────► │ Prometheus │ ──► Alertmanager ──► webhook
                 │  :8000       │                     └─────┬──────┘
                 │              │  файл /logs/app.log       │ запрос метрик
                 │              │ ──► Promtail ──► Loki ─────┼──────► Grafana (дашборд + логи)
                 │              │                           │
                 │              │  OTLP :4317               │
                 │              │ ─────────────────► Jaeger :16686
                 └──────────────┘
```

## 4. Сервис: эндпоинты

| Эндпоинт | Что делает |
|----------|------------|
| `GET /` | страница управления с кнопками |
| `GET /error` | всегда отвечает кодом **500**, спан помечается как ошибочный |
| `GET /slow` | отвечает через случайные **1–3 секунды**, внутри вложенный спан `slow-operation` |
| `POST /load?target=error\|slow\|fast&seconds=90` | запускает равномерную самонагрузку выбранного типа на N секунд (по умолчанию 90) |
| `GET /metrics` | метрики в формате Prometheus |
| `GET /healthz` | проверка живости |

Метрики RED:
- `http_requests_total{method,path,status}` — счётчик (Rate и Errors);
- `http_request_duration_seconds_bucket{method,path}` — гистограмма (Duration).

Логи — JSON, одна строка на запрос, поля: `time, level, message, method, path, status, duration_ms, trace_id`.

## 5. Метрики на дашборде и обоснование

Дашборд **RED — demo-service** в Grafana (папка General). Панели:

1. **Request Rate** — `sum(rate(http_requests_total[1m]))`.
2. **Error Rate, %** — доля ответов 5xx.
3. **Duration** — p50 / p95 / p99 времени ответа.

## 6. Логи

Promtail читает `/logs/app.log`, парсит JSON, добавляет метки `level` и `path`, отправляет в Loki. Просмотр: Grafana → Explore → источник **Loki**.

Пример запроса для поиска ошибок:

```logql
{job="demo-service", level="ERROR"}
```

> 📸 **Скриншот 6:** Grafana Explore с логами ошибок, в развёрнутой строке виден `trace_id` и `status=500`.

## 7. Трейсы

Сервис инструментирован OpenTelemetry (автоматическое трейсирование входящих запросов + ручные спаны). Трейсы уходят в Jaeger по OTLP на `jaeger:4317`. Просмотр: http://localhost:16686, service = `demo-service`.

- медленный запрос `/slow` — «водопад» с вложенным спаном `slow-operation`;
- ошибочный запрос `/error` — спан со статусом error (красный), во вкладке есть событие exception;
- `trace_id` из строки лога можно вставить в поиск Jaeger и открыть тот же самый запрос.

> 📸 **Скриншот 7:** список трейсов в Jaeger.
> 📸 **Скриншот 8:** водопад медленного запроса со вложенным спаном.
> 📸 **Скриншот 9:** трейс с ошибочным (красным) спаном.
